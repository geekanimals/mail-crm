# Geek CRM – Frontend (Next.js, JSX)

```bash
cp .env.local.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:5001
npm install
npm run dev                        # http://localhost:3000
```

- All pages/components are `.jsx` files in `src/`
- All styles are in one file: `src/app/globals.css`
- Logo: replace `public/logo.svg` (or set `NEXT_PUBLIC_LOGO_URL`)

See the main README in the project root for the full setup.
